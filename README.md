# FGId Scenes for IngeTrazo

Manage saved views from the Scenes panel. Set the order, add descriptions and thumbnails, select which properties each scene recalls, and play the scenes included in animation.

## Installation

Extract the release ZIP. Open **Extensions → Open plugins folder** in IngeTrazo and copy the entire FGId_Scenes folder there. Restart IngeTrazo and open **Scenes** in the Properties tray.

Use **+ Scene** to capture the current view and **Update** to refresh the selected scene. Double-click a scene to recall it. Use the arrows to change its position. **Play / Stop** advances through included scenes every two seconds.

The tested version is IngeTrazo 0.5.10.1. Scene settings are stored in the IGZ. The axes checkbox saves axis visibility. Hidden geometry recall is scoped to the model root and identifies geometry by coordinates. Playback switches between saved views every two seconds.
